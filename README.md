# Aziz's Portfolio (2024 edition)

> **This is my previous portfolio, kept for history.**
> The current one lives at **[azyzex.github.io/AzyzPortfolio](https://azyzex.github.io/AzyzPortfolio/)** ([source](https://github.com/azyzex/AzyzPortfolio)).

A one-page static portfolio built with HTML, CSS, Bootstrap and a handful of jQuery plugins (typed text, counters, isotope project filter, lightbox, carousel). The contact form sends mail through EmailJS.

Live: [azyzex.github.io/AzizPortfolio](https://azyzex.github.io/AzizPortfolio/)

## Run it

No build step — open `index.html`, or serve the folder:

```bash
npx serve .
```

## Built with

HTML5 · CSS3 · Bootstrap · jQuery · WOW.js / Animate.css · Typed.js · Isotope · Owl Carousel · EmailJS
